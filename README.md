# 📊 Simple Linear Regression: Predicting Sales from TV Advertising

A beginner-friendly machine learning notebook that models sales as a function of TV advertising spend using simple linear regression, following the equation Sales = m x TV + c.

## Workflow

1. Understand the dataset and handle null values
2. Visualise the data with scatter plots and a correlation heatmap
3. Build a simple linear regression model (supervised learning)
4. Split the data into train and test sets and train on the training set
5. Fit with statsmodels OLS to read the slope, intercept and R-squared
6. Evaluate the model with R-squared

## Tech Stack

Python, Pandas, NumPy, Matplotlib, Seaborn, scikit-learn, statsmodels, Jupyter Notebook

## Repository Contents

- `Simple-Linear-Regression-1411.ipynb`: the full notebook with notes in markdown cells

## How to Run

1. Clone the repository
2. Install the libraries: `pip install pandas numpy matplotlib seaborn scikit-learn statsmodels jupyter`
3. Update the dataset path in the notebook to your local copy
4. Run the cells in order with `jupyter notebook`
